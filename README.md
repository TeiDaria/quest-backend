# Серверная часть системы управления квестами и сюжетными ветками игры

Курсовая работа по дисциплине "Проектирование и разработка серверных частей интернет-ресурсов".
Студент: Стыцюк Д.С.
Группа: ИКБО-20-24

## Стек технологий:
- Язык: PHP 8+
- СУБД: MySQL (InnoDB)
- Веб-сервер: Nginx + PHP-FPM
- Архитектура: Clean Architecture
- Окружение: Docker Compose

## Запуск проекта:
1. Склонируйте репозиторий.
2. Выполните `docker-compose up -d`.
3. API будет доступно по адресу `http://localhost:8080`.
